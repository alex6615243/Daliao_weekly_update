大寮召會週訊一鍵更新程式（多人桌面版）
======================================

分發方式
1. 將「大寮召會周訊一鍵更新程式_桌面版.zip」傳給使用者。
2. 使用者必須先將 ZIP 完整解壓縮，不能直接在 ZIP 裡執行。
3. 雙擊「一鍵更新大寮周訊_桌面版.cmd」。
4. 新 Word 檔與「更新摘要.txt」會直接放到該使用者的桌面。

程式包內容
- 一鍵啟動檔
- 網頁下載與 Word 更新程式
- 參考範本.docx（以核准的 2026.08.2_1.docx 為基準）
- config.json

安全規則
- 參考範本永不覆寫。
- 桌面已有同名檔時，自動改用「_自動更新_1」等新名稱。
- 網站日期不是本週主日時，安全停止且不產生檔案。
- 強制略過網站快取，讀取最新頁面。
- 《代禱事項》保持原樣。

系統需求
- Windows 10 或 Windows 11
- Microsoft Word（用於開啟與最後核對）
- Codex 已安裝並至少開啟過一次，供程式使用隨附的 Python 文件處理環境

注意：請傳送整個 ZIP，不要只傳 CMD，否則會缺少參考範本與程式元件。
